# An AX Task can run ordinary code or an agent

An AX **`Task` is an isolated execution environment**, not a choice between “deterministic job” and “AI operation.” Its `spec.image` and `spec.command` specify what program to launch; the runner prepares the workspace and starts that command as a child process. AX does not inspect whether the child is an agent ([Task schema](https://github.com/google/ax/blob/e09ed1bc5463ad4b5ca88f755a6e1e2005b3c7b7/pkg/apis/v1alpha1/ax.proto#L60-L91), [runner launch](https://github.com/google/ax/blob/e09ed1bc5463ad4b5ca88f755a6e1e2005b3c7b7/runner/runner.go#L167-L195)).

- `command: ["sh", "-lc", "echo ok > /workspace/result.txt"]` runs ordinary scripted code. Whether it is fully reproducible depends on its inputs and environment, not on AX.
- `command: ["python3", "agent.py"]` **could** run an LLM-powered coding agent, if that executable, its prompts/tools, and credentials are supplied in the image or workspace. The agent can plan, call tools, and edit a repository; those behaviors belong to the program, not AX ([Task concept](https://github.com/google/ax/blob/e09ed1bc5463ad4b5ca88f755a6e1e2005b3c7b7/docs/concepts.md#L5-L9), [runner contract](https://github.com/google/ax/blob/e09ed1bc5463ad4b5ca88f755a6e1e2005b3c7b7/docs/runner.md#L9-L26)).
- With **no** `spec.command`, the default runner launches no user workload and stays up serving metadata. A Workspace binding's `goal` is a *one-time environment preparation* request, not the ongoing objective of the task agent ([runner no-command path](https://github.com/google/ax/blob/e09ed1bc5463ad4b5ca88f755a6e1e2005b3c7b7/runner/runner.go#L155-L172), [Workspace goal](https://github.com/google/ax/blob/e09ed1bc5463ad4b5ca88f755a6e1e2005b3c7b7/docs/concepts.md#L22-L32)).

In the [three-agents-one-repository example](three-agents-edit-one-repo.md), each Task's shell command first invokes an actual agent SDK helper to propose a file edit, **then** runs ordinary Git commands to create its patch. The helper is repurposed for teaching, not a production agent harness ([worked command](three-agents-edit-one-repo-guide.md)). `Ready` only says the sandbox/workspace is ready; AX does not receive the child command's exit code ([runner contract](https://github.com/google/ax/blob/e09ed1bc5463ad4b5ca88f755a6e1e2005b3c7b7/docs/runner.md#L30-L43)).
