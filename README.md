# What is Google's AX, and how do you use it?

[AX](https://github.com/google/ax) is a declarative orchestration runtime for isolated agent workloads. The research starts with [what AX does and a path to a first task](what-is-ax.md): its Task, Workspace, and Model resources; the role of Agent Substrate; the CLI workflow; and the deployment prerequisites.

On a bare Apple Silicon Mac, read [how to try AX without or with a local Kubernetes cluster](getting-started-on-mac.md). The cluster-backed path is an unexecuted experiment, not a verified one-command setup.

Published site: [smith.wiki/google-ax](https://smith.wiki/google-ax/).

This is an initial reading of the upstream project, not a report of a working cluster deployment. AX [warns that its concepts and protocols may change before a stable release](https://github.com/google/ax/blob/e09ed1bc5463ad4b5ca88f755a6e1e2005b3c7b7/README.md).
